# Club Social Hub · mobile demo

A clickable demo of the CUNY SPS Club Social Hub mobile design, built for the CUNY SPS AI Club pilot.

**Live demo:** https://missme2026.github.io/club-hub-demo/

- Sample data only. Nothing connects to real social accounts, and nothing is posted anywhere.
- Refreshing the page resets the demo.
- On a phone, open the link in Safari and tap Share → Add to Home Screen to install it like an app.
